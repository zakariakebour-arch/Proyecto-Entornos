ZapStore

He creado ZapStore, una tienda online de zapatos, utilizando PHP para el backend y MySQL como base de datos. En este proyecto he conseguido que los usuarios puedan navegar por los productos, añadirlos al carrito y consultar los detalles completos de cada producto de forma segura.

Me he asegurado de que todas las consultas a la base de datos sean preparadas y parametrizadas, previniendo cualquier intento de inyección SQL y manteniendo el proyecto protegido frente a ataques comunes.

En el frontend he utilizado JavaScript junto con la API IntersectionObserver para que los productos y las tarjetas aparezcan de forma animada al hacer scroll, mejorando la experiencia de usuario y haciendo la página más atractiva.

Además, me he encargado de explicar cada parte del código de todo el proyecto, facilitando su comprensión y mantenimiento.

Tecnologías utilizadas

PHP: Para la lógica del backend, manejo de sesiones y consultas seguras a la base de datos.

MySQL: Para almacenar la información de usuarios, productos y pedidos.

JavaScript: Para las animaciones de los productos al hacer scroll utilizando IntersectionObserver.

HTML / CSS: Para la estructura y el diseño responsivo de la página.

Flexbox y Grid: Para organizar el layout de forma clara y adaptable.

Contraseñas seguras: Almacenadas mediante hash en la base de datos.

Lo que he logrado

Crear un catálogo completo de productos, incluyendo nombre, descripción, precio, imagen y video.

Como buena práctica, crear un archivo llamado conexion.php que contiene la conexión a la base de datos y retorna dicha conexión en una variable. De esta forma, si es necesario cambiar algún dato (como el host al desplegar el proyecto), solo es necesario modificar un único archivo.

En la carpeta conf, crear un archivo llamado footer.php que contiene el footer del sitio, permitiendo reutilizarlo en varias páginas mediante include y evitando la repetición de código.

Implementar un carrito de compras que calcula automáticamente la cantidad total de productos y el precio acumulado.

Lograr que los productos aparezcan con animaciones suaves gracias a JavaScript e IntersectionObserver.

Garantizar la seguridad en todas las consultas mediante prepared statements, protegiendo contra inyecciones SQL.

Desarrollar un diseño completamente responsivo, adaptable a cualquier tipo de pantalla, desde escritorio hasta dispositivos móviles.

Conseguir una interfaz limpia y profesional, facilitando la navegación y la experiencia del usuario.
